# SOP-005 Immunoassay Conjugate Handling (version 2)

## Purpose

Synthetic document. Calder Ridge Diagnostics and everything described here are invented for a retrieval evaluation demo.

This procedure defines how Calder Ridge Diagnostics performs immunoassay conjugate handling. It belongs to the Manufacturing area. Document number SOP-005, version 2, status current.

## Scope

SOP-005 applies to Immunoassay products. It covers routine operation and does not cover validation studies.

## Definitions

Deviation: an unplanned departure from an approved procedure. Change control: the documented review and approval of a change before it is made. Process owner: the person accountable for immunoassay conjugate handling.

## Responsibilities

The process owner maintains SOP-005. Operators follow it and record their work. Quality reviews the records and assesses any deviation under SOP-002.

## Parameters

The controlled parameters for SOP-005 Immunoassay Conjugate Handling, version 2, are:

- Maximum cumulative light exposure: 20 minutes
- Maximum conjugate hold time: 48 hours
- Container type: amber, closed

## Procedure

1. Dispense conjugate under reduced lighting.
2. Record the start and end time of every light exposure.
3. Return conjugate to cold storage between operations.
4. Raise a deviation if cumulative exposure exceeds the limit.

## Records

Records generated under SOP-005 are kept with the batch record or the quality system file and are subject to SOP-001 Document Control.
